ChatGPT TOC Extension

A maintained fork with current ChatGPT markup support, compact prompt summaries, and a redesigned light/dark outline sidebar.

Download ZIP View on GitHub

Install and Preview

Download and extract the ZIP, then load the folder containing manifest.json at chrome://extensions/. Open ui-preview.html from the extracted folder for an offline UI demo. The video below shows the original upstream version, not this fork's redesigned UI.

Key Features

🧭 Easy Navigation

Jump to any section of your ChatGPT conversation instantly with a clickable table of contents.

⚡ Auto-Generated

After installation, the outline updates as loaded messages change. Both legacy and current message markup are supported; only messages mounted in the page are indexed.

🎨 Clean Sidebar

Compact two-line prompt summaries, heading counts, nested collapse controls, and light/dark themes keep long conversations easier to navigate.

🔒 Privacy First

The extension processes loaded message text locally and does not upload conversations. This does not describe ChatGPT or third-party resources on this website.
